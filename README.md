This project is inspired by **[Legacy Sensor by itsVexor]** and uses the original `kinect10.dll` from his project. Full credit for the original DLL goes to itsVexor.

This application is written entirely in Python to keep it lightweight and easy to maintain.

### Available Features

Currently, you can use the following devices for tracking and control:

- **PlayStation Camera:** Use a PS Camera with PSCam4Win for tracking.
- **Webcam:** Use your regular webcam for tracking.
- **DualShock 4:** Use a PS4 controller as a hand controller.

### Virtual Phone

This application also supports **Virtual Phone**, allowing you to track your right arm using a camera and simulate a phone controller for songs that don't support Kinect or camera-based tracking.

### Compatibility

This application is also compatible with:

- **Legacy Offline PC**
- **Just Dance 2022 PC** by Dreyn
